# Variables, engine and per-skill calculation specs

Generated by `scripts/build_variables.py`, `build_glossary.py`, `build_statics.py`, `build_engine.py`, `build_calc_spec.py` (`scripts/pipeline.sh` runs everything).
Everything is read from the Android client (`libil2cpp.so`) offline; label **Code** unless a glossary entry says **Inferred**.

| File | What it is |
|---|---|
| `variables.json` | glossary: every variable / helper / enum / static table the skill formulas use: Thai+English meaning, evidence label, decoded definition (cases, effects, named sub-expressions), references, skills that use it |
| `skill_variables.json` | uid -> glossary ids used by the skill + the client functions (hooks) that read the skill |
| `calc_spec/<uid>.json`, `calc_spec_index.json` | per-skill spec for a damage calculator: input fields, damage-template terms with conditions, effects, buffs (counter state, constructor args), passives, hooks, variables, residual markers |
| `engine.json` | shared engine: CalcStep list, GetDamage arithmetic, what TemplateAssignment puts in each step, helper and status-getter ids |
| `static_arrays.json` | client constant tables (e.g. `SacredTeachings.TargetHealSkills`) decoded from `.cctor` + metadata blobs |
| `unresolved.csv` | audit of the Thai pages (`scripts/audit_unresolved.py`) |

Viewer: **Variables** tab (whole glossary) and the **Variables** / **Calc spec** sub-tabs of the Skills tab (`viewer/toram_viewer.py`).
Reference evaluator: `scripts/calc_engine.py` (`--selftest`, `--coverage`).
