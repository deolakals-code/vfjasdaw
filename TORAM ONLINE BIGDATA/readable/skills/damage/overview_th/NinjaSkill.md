### นินจาสปิริต (ShinobiWay) · uid 1217
- ทรี: สกิลนินจา · เลเวลสูงสุด: 1 · อาวุธที่ใช้ได้: มือเปล่า, ดาบมือเดียว, ดาบสองมือ, ธนู, โบว์กัน, ไม้เท้า, อุปกรณ์เวท, สนับมือ, ทวน, คาตานะ

#### 1) ตัวคูณดาเมจมาจากไหน
- สกิลนี้ไม่มี damage term ที่ถอดได้ (บัพ/พาสซีฟ/ซัพพอร์ต หรือคำนวณฝั่งอื่น)

#### 3) ระหว่างใช้สกิล
- พาสซีฟ/มาสเตอรี่: ความแม่น (`Hit`) → Lv1 1 · Lv5 5 · Lv10 10 — Code
- พาสซีฟ/มาสเตอรี่: ค่าเปอร์เซ็นต์ (`Percent`) → Lv1 -1 · Lv5 -5 · Lv10 -10 — Code
- พาสซีฟ/มาสเตอรี่: Flee (`Flee`) → Lv1 1 · Lv5 5 · Lv10 10 — Code
- ข้อความในเกม (คำอธิบาย): ช่วยเพิ่มหลบหลีกและลดเฮทลงอย่างละเล็กน้อย — Text
- ผลตามข้อความข้างบนไม่ได้ตั้งผ่านการเรียกสถานะใน action; ฟังก์ชันที่อ่านบัพ/สกิลนี้เกี่ยวกับดาเมจที่ได้รับ: ยังไม่พบ (ดู 'ที่ยังไม่รู้' ใน README) — Inferred

#### 5) เชื่อมกับสกิลอื่น
- ไม่พบ

- ข้อความในเกม (Lv255): เปลี่ยนหินรอบบริเวณเป็นดังโล่ ลดความเสียหายระยะไกล — Text
- ผลตามข้อความข้างบนไม่ได้ตั้งผ่านการเรียกสถานะใน action; ฟังก์ชันที่อ่านบัพ/สกิลนี้เกี่ยวกับดาเมจที่ได้รับ: ยังไม่พบ (ดู 'ที่ยังไม่รู้' ใน README) — Inferred

- ถูกอ่านโดย ระบบ/เอนจิน ผ่าน `UIExSkillManager.ExSkillList` (GetSkillLv) — Code
- ถูกอ่านโดย ระบบ/เอนจิน ผ่าน `UIShortcutCustomSkill.SetSkillDataList` (GetSkillLv) — Code
